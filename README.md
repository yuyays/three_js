# Pinch 101 (Web XR/VR app)

## Features
with your VR devices(tested with vision pro)
- click object swiches the color.
- grab a object with pinching action.
- expand a object by piching both with both hands.
- rotate a object by pinching a object in one hand and circle around with another hand.

# Tech stack
- Powered with [Vite](https://vite.dev/) 
- Three.js
- Typescript 
- Shader support (glsl) with[vite-plugin-glsl](https://github.com/UstymUkhman/vite-plugin-glsl) 🎨


## Check it out

I use this starter boilerplate [here](https://github.com/alvarosabu/modern-three)


```bash
git clone https://github.com/yuyays/three_js.git
cd three_js
pnpm i
```

### Use it

```
pnpm dev
```
